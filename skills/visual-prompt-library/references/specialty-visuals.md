# 专项视觉模板

## I1 · 儿童蜡笔旅行日记

- 模板：9:16 竖幅蜡笔旅行手账，以【城市、天数】为主题。用一条弯曲的虚线串起【按顺序排列的站点】，每站用一个大而好认的地标或食物小画。暖浅纸底、红黄蓝绿蜡笔、手写短标签，边缘可点缀当地小吃、路牌或背包人物。
- 用户给了行程就照给定顺序。需要建议路线时，先核对站点与当地信息，再写出图标签。较长的说明可排在图外。生成后检查路线顺序、地名和箭头方向。
- [ZeroLu 3.2 儿童蜡笔旅行日记](https://github.com/ZeroLu/awesome-nanobanana-pro/blob/83fab46434881d0e86544a6b9820085078a3aaf6/README.md#L1349)

## E1 · 电商虚拟模特试穿

- 模板：图 1 为服装商品图，图 2 为模特图。生成【全身或按商品需要的景别】电商试穿照。保留模特的脸、身形与姿势，按姿态重建服装的垂坠、褶皱和遮挡，匹配图 2 的光向与色温。
- 商品图决定版型、长度、领口、袖型、材质、颜色、图案和标志位置。有正背面或局部图时按编号注明各自用途。需要精确展示实物时，以商品图核对细节；试穿图用于视觉展示。
- P5 优先处理真人换装时的身份与造型，E1 优先核对电商服装的还原程度。

## E2 · 3D Q 版微缩品牌店

- 模板：以【品牌代表产品或包装】的形状建成一家可辨认的 3D 微缩店。用【品牌主色】设计门头和室内，透明橱窗透出暖光与有辨识度的店内陈列。选一个能同时看到门面和侧墙的角度，用微缩店员、路人和一两件街景道具建立比例。默认参考 2:3 竖幅和玩具模型质感。
- 视觉焦点放在产品造型如何成为门店结构。真实品牌按参考锁轮廓、配色和指定标识，人物与街景控制在次级层。
