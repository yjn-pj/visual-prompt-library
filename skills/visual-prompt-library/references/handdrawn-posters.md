# 手绘海报模板

H1 适合要逐项查读的清单和导览。H2 适合一句话海报、情绪短卡和少量行动提示。用户只要求换文案时，保留所选模板的阅读顺序和视觉重点，再按新文案调整行宽、角色动作与留白。

## H1 · 彩铅手绘导览

- **版式**。竖版 4:5 起步。上方用可可色粗标题和珊瑚红大数字建立阅读入口。中段用一整块奶油白波浪边展板承载目录。每组用彩色圆角标题签，项目较多时排成两列。总数醒目，每组计数靠右。
- **角色与画风**。奶油黄纸底、彩铅颗粒、细而微抖的棕色轮廓。两位小角色分别放在右上和左下，用朝向、手势和短对白引导读者。允许角色压住展板边缘，给正文和编号留出安全距离。
- **可替换字段**。标题、总数、分组名、编号、条目原文、角色或吉祥物、手中道具、两句导览对白。由实际条目计算总数和分组数量。没有编号的清单可省去编号。
- **出图方法**。条目多、文案必须逐字一致时，先生成透明底角色，再排标题、对白、编号和目录。验收时逐项对照原文，重点看长条目、标点、总数和角色叠放。
- **样例**。用户已认可的 24 项视觉技能总览。右上小女孩举铅笔引出封面图，左下星星举画本提示试穿和棚拍。[原创预览](../assets/poster-pencil-guide.jpg)

## H2 · 粗笔手写便签

- **版式**。竖版 3:4 起步。顶部是超大黑色手写主标题，橘色不规则圈线只圈关键词，下一行用橘色粗笔划出副标题。中段左侧放半身角色，右侧留出短清单，用柠檬黄笔划和橙黄勾号引导阅读。底部用一块亮黄色圆角底托住收尾句。
- **角色与画风**。暖象牙白底、扁平贴纸插画、圆润笔触、略歪的字形。角色的表情和动作回应主题。少量粉色爱心或黄色四角星放在文字间的空处。主标题优先，其次是角色和收尾句。
- **可替换字段**。主标题、圈出的关键词、副标题、角色与道具、短清单、收尾句。可先按一条标题、一句副标题、三条短行动和一句收尾构图，再按文案取舍。收尾句单独占一行。
- **出图方法**。短文案可在图片 brief 中按区域逐字给出，要求生成粗笔手写字。核对每个字、圈线对象、清单顺序和收尾行。遇到错字或行宽溢出时，修正对应区域，或生成插画底图后补排。
- **样例**。「今天也辛苦啦」，圈出「辛苦啦」。副标题「给自己放个小假」。左侧是一只双手捧热茶的垂耳兔。右侧写「喝杯热茶」「听首喜欢的歌」「早点休息」，底部写「今晚先歇一歇」。[原创预览](../assets/poster-handlettered-note.jpg)
