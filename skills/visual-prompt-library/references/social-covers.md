# 社媒封面与横幅模板

C8–C10 是约 3:4 的竖长封面，原图均为 1197 × 1600。C11–C12 是 16:9 的横长图，原图均为 1600 × 900。按所选模板的方向构图。若平台另有尺寸要求，按新画幅重新分配标题、主体和标签的位置。

版式从用户提供的参考图中提炼。成图使用本次给定的文案和主体。样图里的现有人像、原文、品牌、标志和水印属于来源素材。用户另附本人或品牌主体时，明确区分身份参考和风格参考。

## C8 · 红描边真人避雷封面

- **用途**。避坑清单、营销拆解、误区纠正、风险提醒。
- **构图**。3:4 竖版。上方约三成排两行超粗字，第一行白字讲主题，第二行亮黄字给判断。用红色干刷圈标记一个关键词。中下部用真人半身抠像和厚深红描边，保留朝侧边提示的手势。左右各留出短标签位置，底部压一条深红色结论条。
- **视觉**。暖棕照片背景，百叶或室内斜光提供轻微纵深；在标题后压暗背景，在脸部保留自然肤色。用黑字亮黄贴片提炼 2–4 条信息。箭头跟随手势引向贴片，避开脸和手。
- **套用**。输入【白字主题】【黄字判断】【红圈关键词】【人物与手势】【短标签】【底栏文案】。先固定脸、手与标题区域，再排贴片。底栏文字长时压缩文案或调整断句，保持主标题字号。

## C9 · 方格纸窗口大字封面

- **用途**。经验发现、入门方法、反常识观点，尤其适合纯文字封面。
- **构图**。3:4 竖版。顶端窄芥末黄窗口栏，灰米底上放占满画面的圆角方格活页纸。纸面有左侧装订孔、左上斜贴纸胶带和轻微叠纸阴影。中心按「开场钩子 → 主题 → 结论」分三至四行，首行最大。
- **视觉**。粗斜黑体，浅灰细方格退到背景。红色手绘圈只强调一个主题词，芥末黄矩形压在结论行底部。下方可加一个表情贴纸和短提示，保留足够页边距。
- **套用**。输入【开场钩子】【主题词】【结论行】【提示短句，可选】【表情贴纸，可选】。先按行确定字宽，再放圈线和底色。句子较长或要求逐字一致时，用无字纸张底图叠排。

## C10 · 大对白框萌宠封面

- **用途**。教程诀窍、干货推荐、清单引入，适合宠物或吉祥物代替讲述人。
- **构图**。3:4 竖版。上半部用接近全宽的白色漫画对白框，深咖手绘粗边和尖尾引向下方主体。框内排两行粗字，讲「办法」和「结果」。下半部右侧放大号拟人萌宠抠像，左侧排 1–2 条短提示，底部可加收藏或阅读提示。
- **视觉**。奶油黄底、深咖线条、橙红粗字，搭配浅黄或淡蓝刷痕。主体可以是真实毛发质感的宠物，也可以是品牌吉祥物。给它安排能说明主题的手持道具，例如笔记本电脑、马克杯、文件夹。
- **套用**。输入【方法主句】【结果短句】【宠物或角色】【主题道具】【左侧提示】【底部文案，可选】。确保对白框尖尾、角色脸和道具都能被认出。双语仅在本次需要时排入。

## C11 · 橙白棋盘欢迎横幅

- **用途**。账号欢迎、栏目预告、关注引导。适合美食、探店和生活方式等轻快内容。
- **构图**。16:9 横版。上、下沿各一条橙白棋盘格。中间约左六成排大标题、频道定位短句和橙色横飘带，右侧约四成放有动作的真人半身抠像。人物指向左侧标题，手指与外轮廓完整保留。
- **视觉**。浅杏色放射线叠白色网点，橙色粗斜标题配厚白描边，人物用橙色粗描边。表情贴纸可作为小面积点缀，背景放射线在文字背后降对比。
- **套用**。输入【欢迎主标题】【频道定位短句】【横条承诺或行动句】【右侧人物及手势】【主色】。查看实际横幅裁切，保住主标题、手势和脸，允许棋盘边缘按平台裁掉。

## C12 · 牛皮纸人像工具箱横幅

- **用途**。专业栏目、职场专题、个人 IP 的内容总览横幅。
- **构图**。16:9 横版。中间放接近全高的真人半身抠像。超大标题按语义拆成左右两段，分别占据人像两侧上方。两翼下方用倾斜的短标签列出内容模块，右下可放小号手写说明。
- **视觉**。暖棕空间底上叠一大块皱纹牛皮纸，边缘压暗。淡黄窄粗刷字加深棕投影，人物用浅黄细描边，标签用珊瑚红底白字。少量手绘箭头、短划线连接标题与标签。
- **套用**。输入【左标题】【右标题】【居中人物及动作】【栏目短标签】【手写说明，可选】。先核对拆开后能按左右顺序读通，再让人像与标题轻微叠层。脸、手和决定字义的笔画都要完整。

带字版按缩略图尺寸检查标题、主题词和主体轮廓，逐字核对标签与底栏。对排字层级复杂或文案必须准确的稿件，可让生成图预留排字区，再叠加文字与标注。
