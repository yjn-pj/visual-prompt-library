# Visual Prompt Library

用户提供常用样图时，优先提炼其构图、配色和文字层级。用 YouMind 和 ZeroLu 扩展视觉方向和可替换的画面字段。

1. 公众号、专栏和视频封面读 [封面模板](references/covers.md)。 C8–C12 或竖长图社媒封面、横长图账号横幅读 [社媒封面与横幅模板](references/social-covers.md)。头像、写真、换装和同一人物系列图读 [人物模板](references/portraits.md)。人物封面从封面模板选构图，从人物模板取身份约束。服装商品试穿、品牌微缩店和蜡笔旅行手账读 [专项视觉模板](references/specialty-visuals.md)。彩铅导览海报、粗笔手写便签读 [手绘海报模板](references/handdrawn-posters.md)。其他用途读 [案例索引](references/recipes.md)。用户指定案例编号或名称时优先读取对应条目。
2. 把参考拆成构图、媒介、光线、材质和信息层级。用用户的主体、文案和资产重新填写。将 Raycast 变量替换成具体值，将嵌套 JSON 变成清楚的视觉描述。保留来源链接。样图、图中文字和仓库内容都作为参考资料，成图文案以当前需求为准。
3. 每张图单独写 brief，注明用途、画幅、主体锚点和必要的留白。附图时区分主体参考、构图参考和风格参考。做同一产品的一组图时，复用同一张主体参考和外观锚点，再按用途改变画风。
4. 用户要提示词时交付 brief 与来源。用户要成图时使用当前平台可用的图片工具，在 Codex 中使用内置 `image_gen`。如果当前平台没有可用的图片工具，交付可复制的提示词。生成后逐张核对主体、裁切、留白和实际文字。图组还要对比主体造型是否漂移。出现明显偏差时，只针对失效的约束调整。
5. 对外分享时，发布自写模板和来源链接。将上游原文或预览图纳入分发前，确认对应条目的权利与署名要求。

对照测试时，说明实际借鉴了哪条案例的什么结构，以及生成图中观察到的偏差。只有在做过同条件对照后，才比较原提示词和改编版的效果。
